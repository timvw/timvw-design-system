Built with timvw

A guide for every building block.

Imports, states, variants and keyboard behavior — with HTML you can take into your own project.

Load exactly the families you use.

The full css/timvw.css, css/components.css and js/timvw.js entry points remain available. For selective loading, start with css/foundation.css and add the listed CSS parts. Import the JavaScript initializer directly from its module. Importing a function from the full JavaScript entry point still fetches its complete dependency graph in a native browser.

<link rel="stylesheet" href="./css/foundation.css">
<link rel="stylesheet" href="./css/parts/buttons.css">
<link rel="stylesheet" href="./css/parts/dialogs.css">
<script type="module">
  import { initDialogs } from './js/dialogs.js';
  initDialogs(document);
</script>

Use class="tvw" on the body. Keep the relative directory structure. Direct modules may import locale.js; dialogs, tabs and templates have no transitive dependencies. Copy the whole JavaScript folder if unsure: the browser only fetches imported modules. Choose either the full CSS pair or foundation + parts to avoid redundant downloads. No consumer build step is required.

Native HTML templates.

A <template id="project-dialog"> is already registered in the document by its ID. Clone its inert content to reuse it. Our optional instantiateTemplate() helper remaps IDs and their label/ARIA/dialog references, and fills data-tvw-text slots with text. It returns a DocumentFragment plus an ID map. Append first, then initialize the container with only the components used.

Listeners are attached after cloning. The source template is trusted HTML; this helper does not sanitize arbitrary HTML. It does not bind arbitrary attributes, execute template expressions or fetch external fragments. For dynamic forms, supply distinct field names if the instances share one form.

import { instantiateTemplate } from './js/templates.js';
import { initDialogs } from './js/dialogs.js';
const template = document.getElementById('project-dialog');
const instance = instantiateTemplate(template, {
  values: { title: 'Project Atlas' }
});
container.append(instance.fragment);
initDialogs(container);

States
Already in HTML, inserted later, attribute update, disconnected and reconnected.
Use & keyboard
Use a hyphenated tag name. data-tvw-text keys bind attributes as text. Register once with registerTemplate; use setup for component initialization and connection cleanup.
CSS parts
Parts used by the template + foundation.css
JavaScript
templates.js: registerTemplate
Copyable example

<message-card heading="Ready" message="Your workspace is available."></message-card>
<script type="module">
  import { registerTemplate } from "./js/templates.js";
  registerTemplate("message-card", document.getElementById("message-template"));
</script>

Foundations & content

Use semantic tokens for colors, spacing and typography. Keep action labels specific: “Save project” rather than “OK”. Describe errors with a problem and a recovery action. Use heading levels to express structure, and text alongside status colors.
