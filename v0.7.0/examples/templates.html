One template. Many dialogs.

This page loads foundation, button and dialog CSS, plus only the dialog and template JavaScript modules. Each instance gets unique IDs and its own focus return.

Define once in HTML

<template id="dialog-template">
  <button type="button" data-tvw-open="dialog" hidden>Open</button>
  <dialog id="dialog" aria-labelledby="title">
    <h2 id="title" data-tvw-text="title">Details</h2>
    <form method="dialog"><button>Close</button></form>
  </dialog>
</template>

Instantiate only what you need

import { initDialogs } from '../js/dialogs.js';
import { instantiateTemplate } from '../js/templates.js';
const instance = instantiateTemplate(template, {
  values: { title: 'Project details' }
});
container.append(instance.fragment);
initDialogs(container);

Templates hold trusted markup. Values are inserted as text. Event listeners are attached after cloning. No custom element registration or framework is required.
