Icons & button variants

Copy icons.svg and reference a symbol with SVG use. Icon-only actions need an accessible name.

Use setBusy(button, true, "Saving…") before asynchronous work and setBusy(button, false) in finally. The preview above deliberately waits briefly; ordinary styled buttons do not supply application actions.

Theme picker

Form validation

Submit an incomplete form to see linked errors. Errors clear as you correct the fields.

The library prevents invalid submissions. Listen for the cancelable tvw:valid-submit event and call preventDefault() to handle a valid form locally; otherwise the form submits normally. The demo cancels submission and sends nothing.

Popovers

Use a nonmodal popover for supplementary content or a short group of controls. Outside click and Escape dismiss it.

With JavaScript disabled, supported browsers still open declarative popovers; the default presentation is centered. The module positions them near their trigger.

Toast notifications

Announce a completed action without interrupting the workflow. Every toast has a dismiss button.

Call notify("Saved.", { tone: "success", duration: 6000 }). By default notifications persist until dismissed. A positive duration pauses while hovered, focused, or the tab is hidden. Important errors should also appear next to the affected content.
