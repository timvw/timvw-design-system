Get started

01 / Foundation

Start with one import: components/page.js includes styles, automatic enhancement and the reusable <tvw-card> and <tvw-dialog> tags. Write your content in native slots. No separate CSS links or init() call.

For a smaller page, import only the component packages you use. Download the runtime bundle and serve it over HTTP.

The manual loading alternative remains available when you need direct control over stylesheets and initialization.

View source
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My project · timvw</title>
  <script type="module" src="./components/page.js"></script>
</head>
<body>
  <main style="max-width: 48rem; margin: 2rem auto; padding: 1rem;">
    <tvw-card>
      <h1 slot="heading">Hello, timvw.</h1>
      <p>Your next project starts with reusable HTML.</p>
      <tvw-dialog slot="actions" open-label="Open project">
        <h2 slot="heading">My project</h2>
        <p>One import includes the components, styles and behavior.</p>
      </tvw-dialog>
    </tvw-card>
  </main>
</body>
</html>

Tabs

HTML + CSS + JS

Arrow keys change tabs; Home and End jump to the first and last. Without JavaScript, all sections stay readable.

Overview

Related content, one section at a time. The selected tab and its panel are linked for assistive technology.

Usage

Give every button and panel a unique ID, import components/tabs.js once. New instances enhance automatically.

Keyboard

Use Left and Right, Home, or End to select a tab. Tab moves into the selected panel.

Accessibility is part of the markup.

The components provide visible focus styles, native controls, and keyboard behavior for tabs and dialogs. Your content and integration still need testing.

  • Use a logical heading order and visible, descriptive labels.
  • Keep errors understandable without relying on color.
  • Test every interaction with only a keyboard and with your target screen readers.
  • Check your custom colors, zoomed layouts, and narrow screens.
  • Keep essential content available when JavaScript cannot load.

This release has no completed manual accessibility audit. See the review findings and test plan for the evidence and remaining checks.
